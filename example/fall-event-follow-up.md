# 낙상 이벤트 이후 안부 확인

연동 기기에서 낙상 의심 이벤트가 들어왔을 때의 목표 시나리오입니다.

1. 연동 기기가 보낸 이벤트를 받아 발생 시각과 출처를 남깁니다.
2. 사용자에게 “기기에서 낙상 의심 이벤트를 보냈어요. 지금 괜찮은지 확인해 주세요.”라고 알리고, 사용자가 상태를 답할 수 있게 합니다.
3. 사용자가 도움을 요청하면 사전에 지정하고 공유를 허용한 연락처에 후속 확인을 요청하는 흐름을 구상합니다. 확인을 기다리는 요청과 사용자 응답은 구분해 표시합니다.

낙상 이벤트 수신부터 알림·연락까지 이어지는 기능은 목표 범위입니다. 현재 런타임에서 이 흐름은 검증되지 않았습니다.
