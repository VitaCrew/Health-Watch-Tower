# 식사 기록과 영양 확인

> “오늘 점심에 먹은 현미밥 150g과 닭가슴살 100g을 기록해줘. 오늘 기록된 단백질 합계도 알려줘.”

1. 필요한 경우 식품 카탈로그에서 식품을 찾고, 입력하려는 음식과 양을 확인합니다.
2. 사용자 확인을 받은 내용을 식사 일지로 저장합니다.
3. 오늘 날짜의 에너지와 탄수화물·단백질·지방 합계를 조회합니다. 나중에 식사량을 수정하면 영향을 받은 날짜의 합계가 다시 계산됩니다.
4. 원하면 저장한 식사 기록에 권한 있는 영양 담당자의 검토 요청을 연결합니다.
