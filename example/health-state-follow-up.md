# 개인 건강 상태 갱신과 후속 확인

> “어젯밤 수면 기록과 오늘 아침 식사 기록이 반영됐는지 보여줘. 어제 남긴 검토 요청도 확인하고 싶어.”

1. 웨어러블 동기화나 사용자 입력으로 새 기록이 들어오면 HSM(Health State Machine)이 수면·영양·복약 등 관련 상태를 갱신합니다.
2. AI는 사용자 권한 범위에서 최신 상태를 조회합니다. 지연되거나 비어 있는 항목은 별도로 보여줍니다.
3. 사용자가 검토를 원하면 AI가 MCP로 검토 요청을 제출합니다. Health Watch Tower는 요청을 기록에 연결하고 현재 권한을 확인해 담당자를 찾습니다. AI가 예약된 후속 확인을 진행할 때는 에이전트 실행 환경의 스케줄러나 워크플로를 사용합니다.

복약 확인의 로컬 실행 예시에서는 OpenHuman의 예약 작업이 HSM의 복약 상태를 조회하고, 설정된 워크플로가 사용자 응답을 받습니다. [복약 확인 예시](medication-confirmation.md)
